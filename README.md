# 截图审判所 · Screenshot Detective

截图与文字公开事实核查网页，连接 Dify 工作流获取回答。

## 文件

- `index.html`：网页界面。
- `api/check.js`：Vercel 服务端接口，接收文字或图片并调用 Dify。
- `vercel.json`：接口运行时长配置。
- `dify/信息检索.ifpkg`：原始 Dify 应用导入包。
- `dify/app.yaml`：从导入包提取的工作流配置，方便查看与维护。

## 部署

1. 在 Dify 中导入 `dify/信息检索.ifpkg`，配置通义模型凭据以及工作流环境变量 `YUANBAO_API_KEY`，并发布应用。
2. 在 Vercel 中导入本 GitHub 仓库，项目根目录保持默认，不需要构建命令。
3. 按需设置 `DIFY_APP_CODE` 和 `DIFY_WEB_API`（见 `.env.example`），然后部署。
4. 使用不含敏感信息的文字和截图分别测试，确认流程返回结果。

原始网页和接口已带有一个 Dify 应用代码，服务端环境变量可以覆盖接口的默认连接。网页还包含直连默认 Dify 应用的备用逻辑；更换应用时，应同时检查并调整该逻辑。

## 数据与使用范围

提交的文字和图片会发送给配置的 Dify 服务及其工作流使用的服务商。不要提交隐私、机密或未获授权的资料。API 密钥应保存在部署平台或 Dify 的环境变量中，不要提交到仓库。

上传 GitHub 仅保存代码，不等于已上线。GitHub Pages 不运行此项目的 `api/check.js` 接口；完整使用建议按上述方式部署。事实核查结果需结合原始来源人工复核。

当前整理已进行 JavaScript 语法检查，尚未验证 Dify 实际调用、模型效果或公网部署。
